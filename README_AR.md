## 📝 مقدمة المشروع

DAZI-AI هو مساعد صوتي ذكي يعمل بدون خادم، تم تطويره بالكامل على منصة ESP32 باستخدام بيئة Arduino. يسمح لك بتشغيل تفاعلات الذكاء الاصطناعي الصوتية مباشرة على أجهزة ESP32 دون الحاجة إلى دعم خادم إضافي. يوفر النظام قدرات تفاعل صوتي كاملة تشمل التعرف على الكلام، ومعالجة الذكاء الاصطناعي، وإخراج تحويل النص إلى كلام.

## 🚀 المميزات الرئيسية

✅ **تصميم بدون خادم**:
- تطوير ثانوي أكثر مرونة
- درجة حرية أعلى (تخصيص التوجيهات أو النماذج)
- نشر أبسط (لا حاجة لخادم إضافي)

✅ **تفاعل صوتي كامل**:
- إدخال صوتي عبر ميكروفون INMP441
- التعرف على الكلام في الوقت الفعلي باستخدام واجهة برمجة تطبيقات ByteDance ASR
- معالجة الذكاء الاصطناعي عبر واجهة برمجة تطبيقات OpenAI
- إخراج صوتي عبر مكبر صوت I2S من نوع MAX98357A

✅ **وضع المحادثة المستمرة**:
- التعرف التلقائي على الكلام مع كشف النشاط الصوتي (VAD)
- حلقة محادثة سلسة: ASR → LLM → TTS
- ذاكرة محادثة قابلة للتكوين للحفاظ على السياق
- تحكم بزر واحد لبدء/إيقاف الوضع المستمر


## 🔧 هندسة النظام

يستخدم النظام تصميمًا نمطيًا مع المكونات الرئيسية التالية:
- **الإدخال الصوتي**: ميكروفون INMP441 مع واجهة I2S
- **التعرف على الكلام**: واجهة برمجة تطبيقات ByteDance ASR للنسخ الآني
- **معالجة الذكاء الاصطناعي**: واجهة برمجة تطبيقات OpenAI ChatGPT للمحادثة مع دعم الذاكرة
- **الإخراج الصوتي**: مكبر صوت I2S من نوع MAX98357A لتشغيل تحويل النص إلى كلام
- **الاتصال**: WiFi للتواصل مع واجهات برمجة التطبيقات

### وضعي المحادثة
1. **وضع الضغط للتحدث** (examples/chat): اضغط مع الاستمرار على الزر للتسجيل، أفلت للمعالجة
2. **وضع المحادثة المستمرة** (examples/chat_asr): ASR تلقائي مع VAD، حلقة محادثة سلسة

## 💻 وصف الكود

### مكتبة DAZI-AI
مكتبة Arduino موحدة تجمع كل المكونات اللازمة لتطوير المساعد الصوتي الذكي.

| الميزة | الوصف |
|---------|-------------|
| التواصل مع ChatGPT | يتواصل مع واجهة برمجة تطبيقات OpenAI، يتعامل مع الطلبات والردود |
| ذاكرة المحادثة | تحتفظ بسجل المحادثة لردود واعية للسياق |
| تحويل النص إلى كلام | وظيفة تحويل النص إلى كلام، تحول ردود الذكاء الاصطناعي إلى صوت |
| تحويل الكلام إلى نص | وظيفة تحويل الكلام إلى نص، تحول مدخلات المستخدم إلى نص |
| ASR في الوقت الفعلي | تكامل ByteDance ASR مع بروتوكول WebSocket للتعرف على الكلام المتدفق |
| VAD | كشف النشاط الصوتي للكشف التلقائي عن الكلام والتعامل مع الصمت |
| معالجة الصوت | معالجة وتحويل تنسيقات بيانات الصوت (معدل من ESP32-audioI2S) |
| تشغيل الصوت | إخراج صوتي I2S مع دعم ترميزات متعددة (MP3, AAC, FLAC, Opus, Vorbis) |

## 🔌 متطلبات الأجهزة

### الأجهزة الموصى بها
- **المتحكم**: لوحة تطوير ESP32 (يوصى بـ ESP32-S3)
- **مكبر الصوت**: MAX98357A أو مكبر I2S مشابه
- **الميكروفون**: ميكروفون INMP441 I2S MEMS
- **مكبر الصوت**: مكبر صوت 4Ω 3W أو سماعات رأس

### توصيلات دبابيس INMP441

| دبوس INMP441 | دبوس ESP32 | الوصف |
|-------------|-----------|-------------|
| VDD | 3.3V | الطاقة (لا تستخدم 5V!) |
| GND | GND | الأرضي |
| L/R | GND | اختيار القناة اليسرى |
| WS | GPIO 4 | ساعة اليسار/اليمين |
| SCK | GPIO 5 | ساعة التسلسل |
| SD | GPIO 6 | البيانات التسلسلية |

### توصيلات دبابيس إخراج الصوت I2S لـ MAX98357A

| الوظيفة | دبوس ESP32 | الوصف |
|----------|-----------|-------------|
| I2S_DOUT | GPIO 47 | إخراج بيانات الصوت |
| I2S_BCLK | GPIO 48 | ساعة البت |
| I2S_LRC | GPIO 45 | ساعة اليسار/اليمين |

## 🚀 البدء السريع

1. **إعداد البيئة**
   - تثبيت [Arduino IDE](https://www.arduino.cc/en/software) (يوصى بالإصدار 2.0+)
   - تثبيت دعم لوحة ESP32 في Arduino IDE:
     - اذهب إلى `File` → `Preferences`
     - أضف رابط مدير لوحة ESP32: `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
     - اذهب إلى `Tools` → `Board` → `Boards Manager`
     - ابحث عن "ESP32" وقم بتثبيت "esp32 by Espressif Systems"

2. **تثبيت المكتبة عبر ZIP**

   **الطريقة 1: التثبيت المباشر عبر ZIP (موصى به)**
   - قم بتنزيل أو إنشاء ملف ZIP لمجلد `DAZI-AI` بأكمله
   - تأكد من أن هيكل ملف ZIP يحتوي على `library.properties` في المستوى الجذري
   - افتح Arduino IDE
   - اذهب إلى `Sketch` → `Include Library` → `Add .ZIP Library...`
   - اختر ملف `DAZI-AI.zip`
   - انتظر حتى يكتمل التثبيت

   **الطريقة 2: التثبيت اليدوي**
   - انسخ مجلد `DAZI-AI` بأكمله إلى دليل مكتبات Arduino الخاص بك:
     - Windows: `Documents\Arduino\libraries\`
     - macOS: `~/Documents/Arduino/libraries/`
     - Linux: `~/Arduino/libraries/`
   - أعد تشغيل Arduino IDE

3. **تثبيت التبعيات المطلوبة**
   - افتح مدير مكتبات Arduino IDE (`Tools` → `Manage Libraries...`)
   - ابحث وقم بتثبيت المكتبات التالية:
     - **ArduinoWebsocket** (الإصدار 0.5.4 أو أحدث)
     - **ArduinoJson** (الإصدار 7.4.1 أو أحدث)
     - **Seeed_Arduino_mbedtls** (الإصدار 3.0.2 أو أحدث)

4. **تكوين مفاتيح واجهة برمجة التطبيقات**

   **لوضع الضغط للتحدث** (`examples/chat/chat.ino`):
   - استبدل `"your-api-key"` بمفتاح OpenAI API الفعلي الخاص بك
   - استبدل `"your-wifi-ssid"` و `"your-wifi-password"` ببيانات اعتماد WiFi الخاصة بك
   - يمكنك تعديل التوجيهات النظامية لتخصيص سلوك الذكاء الاصطناعي

   **لوضع المحادثة المستمرة** (`examples/chat_asr/chat_asr.ino`):
   - استبدل `"your-bytedance-asr-api-key"` بمفتاح ByteDance ASR API الخاص بك (السطر 37)
   - استبدل `"your-openai-api-key"` بمفتاح OpenAI API الخاص بك (السطر 41)
   - استبدل بيانات اعتماد WiFi (السطرين 33-34)
   - عيّن `ENABLE_CONVERSATION_MEMORY` على 1 لتمكين الذاكرة أو 0 لتعطيلها (السطر 7)
   - يمكنك تعديل التوجيهات النظامية لتخصيص شخصية الذكاء الاصطناعي (الأسطر 81-104)

5. **توصيل الأجهزة**
   - قم بتوصيل ميكروفون INMP441 وفقًا لجدول الدبابيس أعلاه
   - قم بتوصيل مكبر الصوت I2S من نوع MAX98357A لإخراج السماعة

6. **فتح مشاريع المثال**
   - بعد تثبيت المكتبة، ستكون الأمثلة متاحة في Arduino IDE
   - اذهب إلى `File` → `Examples` → `DAZI-AI`
   - اختر إما:
     - **chat**: مثال وضع الضغط للتحدث
     - **chat_asr**: مثال وضع المحادثة المستمرة

7. **التجميع والتحميل**
   - اختر لوحة تطوير ESP32 المناسبة
     - تم اختبار هذا المشروع على ESP32S3 Dev Module و XIAO ESP32S3
     - المتطلبات: حجم الفلاش >8M و PSRAM >4Mb
   - في Arduino IDE، قم بتكوين إعدادات اللوحة:
     - Partition Scheme: اختر "8M with spiffs"
     - PSRAM: اختر "OPI PSRAM"
   - قم بتجميع وتحميل الكود إلى جهازك

8. **الاختبار**
   - افتح نافذة التسلسل (115200 باود)
   - انتظر اتصال WiFi
   - اضغط مع الاستمرار على زر BOOT في ESP32 الخاص بك لبدء التسجيل
   - تحدث بسؤالك أو أمرك أثناء الضغط على الزر
   - أفلت الزر لإرسال التسجيل إلى ChatGPT
   - استمع إلى رد الذكاء الاصطناعي من خلال السماعة المتصلة
## 📚 مشاريع مثال

### 1. الدردشة الصوتية بالضغط للتحدث (examples/chat)
نظام تفاعل صوتي تقليدي بالضغط للتحدث مع ChatGPT.

**المميزات:**
- تسجيل صوتي بالضغط للتحدث مع ميكروفون INMP441 باستخدام زر BOOT
- تحويل الكلام إلى نص باستخدام واجهة برمجة تطبيقات OpenAI Whisper
- معالجة محادثة ChatGPT مع توجيهات نظام قابلة للتخصيص
- إخراج تحويل النص إلى كلام مع تشغيل صوت طبيعي
- معالجة صوتية في الوقت الفعلي وإخراج صوتي I2S
- نقاط نهاية واجهة برمجة تطبيقات قابلة للتكوين لخدمات متوافقة مع OpenAI مختلفة

**طريقة الاستخدام:**
- اضغط مع الاستمرار على زر BOOT لبدء التسجيل الصوتي
- تحدث أثناء الضغط على الزر
- أفلت الزر لإيقاف التسجيل وإرساله إلى ChatGPT
- سيقوم النظام بتحويل كلامك إلى نص وإرساله إلى ChatGPT
- سيتم تشغيل رد ChatGPT ككلام من خلال السماعة

**التحكم:**
- يستخدم النظام زر BOOT المدمج في ESP32 (GPIO 0) للتحكم الصوتي
- اضغط مع الاستمرار للتسجيل، أفلت للمعالجة
- لا حاجة لكتابة أوامر في نافذة التسلسل - استخدم الزر فقط!

### 2. وضع المحادثة المستمرة (examples/chat_asr) ⭐ جديد
محادثة صوتية مستمرة متقدمة مع ASR في الوقت الفعلي وذاكرة محادثة.

**المميزات:**
- **ASR في الوقت الفعلي**: واجهة برمجة تطبيقات ByteDance ASR للتعرف على الكلام المتدفق
- **VAD (كشف النشاط الصوتي)**: اكتشاف تلقائي لبداية ونهاية الكلام
- **حلقة محادثة سلسة**: دورة تلقائية: ASR → LLM → TTS → ASR
- **ذاكرة المحادثة**: تحافظ على السياق عبر عدة أدوار محادثة
- **تحكم بزر واحد**: ضغطة زر واحدة لبدء/إيقاف الوضع المستمر
- **مهلات زمنية ذكية**: خروج تلقائي من الوضع المستمر إذا لم يتم اكتشاف كلام
- **تصميم آلة الحالة**: إدارة حالات قوية لانتقالات سلسة

**كيف تعمل:**
1. **اضغط على زر BOOT** → يدخل وضع المحادثة المستمرة
2. **استماع ASR** → يبدأ النظام في الاستماع للكلام تلقائيًا
3. **اكتشاف الكلام** → VAD يكتشف عندما تبدأ وتتوقف عن الكلام
4. **معالجة تلقائية** → يرسل النسخ إلى ChatGPT تلقائيًا
5. **تشغيل TTS** → تشغيل رد الذكاء الاصطناعي عبر السماعة
6. **دورة تلقائية** → يعود النظام تلقائيًا إلى حالة الاستماع
7. **اضغط على زر BOOT مرة أخرى** → خروج من الوضع المستمر

**خيارات التكوين:**
- `ENABLE_CONVERSATION_MEMORY`: تشغيل/إيقاف سجل المحادثة (السطر 7)
- `systemPrompt`: تخصيص شخصية وسلوك الذكاء الاصطناعي (الأسطر 81-104)
- `setSilenceDuration()`: ضبط عتبة اكتشاف الصمت (السطر 194)
- `setMaxRecordingSeconds()`: تعيين الحد الأقصى لمدة التسجيل (السطر 195)

**طريقة الاستخدام:**
- اضغط على زر BOOT مرة واحدة لبدء وضع المحادثة المستمرة
- تحدث بشكل طبيعي - سيكتشف النظام عندما تبدأ وتتوقف عن الكلام
- تشغيل ردود الذكاء الاصطناعي تلقائيًا
- يعود النظام إلى الاستماع بعد كل رد
- اضغط على زر BOOT مرة أخرى للخروج من الوضع المستمر

**آلة الحالة:**
```

ساكن → يستمع → معالجة LLM → تشغيل TTS → انتظار اكتمال TTS → يستمع (دورة)

```

**المزايا:**
- لا حاجة للضغط على الزر أثناء التحدث
- تدفق محادثة طبيعي كالتحدث مع شخص
- ردود واعية للسياق مع ذاكرة المحادثة
- اكتشاف صوتي تلقائي يلغي التحكم اليدوي
